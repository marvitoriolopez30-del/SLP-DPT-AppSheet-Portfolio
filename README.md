# SLP Data Project Tracker (SLP DPT)

## Overview

The **SLP Data Project Tracker (SLP DPT)** is an AppSheet application I developed for the **Department of Social Welfare and Development (DSWD)** under the **Sustainable Livelihood Program (SLP)**.

The application was created to digitize and streamline project monitoring, grant utilization tracking, beneficiary management, and reporting. It replaced manual processes with a centralized system that allows staff to monitor project progress, capture field monitoring data, and generate reports more efficiently.

---

## My Role

I was responsible for:

- Designing and developing the AppSheet application
- Creating the database structure using Google Sheets
- Implementing workflows and business logic
- Building dashboards and reports
- Configuring role-based user access
- Creating forms with validation rules
- Testing, deployment, and continuous improvements
- Providing user support and enhancements

---

# Key Features

### Project Monitoring
- Monitor livelihood projects across multiple municipalities
- Track project implementation status
- Record monitoring visit details

### Grant Utilization Tracking
- Track Grant Utilization Report (GUR) activities
- Record findings and recommendations
- Monitor compliance and project progress

### Beneficiary Management
- Centralized beneficiary database
- Search and filter records
- View project history

### Field Monitoring
- Capture monitoring photos during field visits
- Store geotagged images
- Record visit timestamps

### Dashboards & Reports
- Real-time project dashboards
- Interactive charts
- Municipality summaries
- Exportable reports

### Data Validation
- Required fields
- Conditional logic
- Dependent dropdowns
- Automated calculations
