# SLP Data Project Tracker (SLP DPT)

> **A digital project monitoring and data management solution built with Google AppSheet for the Sustainable Livelihood Program (SLP).**

## Overview

The **SLP Data Project Tracker (SLP DPT)** is a digital monitoring application I designed and developed to improve project monitoring, Grant Utilization Report (GUR) tracking, field data collection, beneficiary/project information management, and reporting for the **Sustainable Livelihood Program (SLP) of the Department of Social Welfare and Development (DSWD)**.

The system was developed to address challenges associated with manual monitoring, fragmented records, data validation, project tracking, and report consolidation.

The application provides a centralized workflow where project and monitoring information can be captured, validated, tracked, and reviewed across multiple municipalities.

---

## The Problem

Before the development of the SLP DPT, project monitoring involved multiple manual processes and separate data sources.

Key challenges included:

* Manual consolidation of monitoring information
* Difficulty tracking project implementation status
* Duplicate or inconsistent participant records
* Time-consuming report preparation
* Limited visibility of project locations
* Difficulty monitoring Grant Utilization Report (GUR) progress
* Repetitive data-entry and validation tasks
* Fragmented monitoring information across different files

---

## The Solution

I designed the **SLP Data Project Tracker** as a centralized AppSheet-based monitoring system.

The application combines structured data management, validation rules, dashboards, field data collection, project location mapping, and reporting workflows into a single platform.

The system was designed to support monitoring activities across **8 municipalities in Aurora Province**.
